# 用户测试与 A/B 协议

## 设计

- A 版本：基础“早八不空档”首屏，优惠券入口普通展示。
- B 版本：同一主题，突出“顺路取杯”和首杯券规则，按钮文案为“领取首杯券”。
- 分组：随机分配，目标每组 20–30 人；本项目样例为每组 12 人，仅演示流程。
- 主要指标：优惠券点击率、购买转化率、券核销率、平均反馈分。
- 次要指标：试饮意愿、购买意愿、品牌契合度（1–5 分）。

## 伦理与限制

只记录匿名 ID、版本和行为结果；用户需同意用于课程分析。样例数据为模拟数据，p-value 仅作计算演示，不能据此宣称统计显著。

## 下一轮

扩大每组样本，分层记录早八/图书馆/社团场景，补充真实核销和库存数据；保留 B 的取杯动线信息，同时单独测试社团套餐，不一次改变多个变量。
