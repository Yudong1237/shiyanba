# Demo Day 8 分钟演示脚本

1. **问题（45 秒）**：Campus Coffee 需要知道校园新品先做什么内容、投什么渠道，以及哪种首屏更能促成首购。
2. **上传与品牌档案（60 秒）**：打开 Streamlit，展示品牌人格、目标人群和历史 Campaign；说明版本为 v1.0。
3. **消费者洞察（75 秒）**：运行后展示主题提及、负向占比和 evidence ID，强调数据已匿名且为模拟样例。
4. **竞品与内容机会（90 秒）**：展示威胁排序、市场空白、我方/竞品内容覆盖和机会分数。
5. **Campaign Planner（75 秒）**：展示主题“早八不空档，第一杯刚刚好”、四类渠道、KPI 和风险审核点。
6. **A/B 与问卷（90 秒）**：比较 A/B 点击率、转化率、uplift 和问卷均值，说明 p-value 不做显著性宣称。
7. **闭环（45 秒）**：展示下一轮建议：保留 B 的取杯动线表达，扩大样本并单独测试社团套餐。
8. **答辩收束（60 秒）**：回答数据来源、程序计算/AI判断边界、证据链和用户测试限制。

录制方式：`streamlit run app.py` 后按上述顺序录屏；本交付物包含完整脚本和截图点位，未伪造视频或实验结果。
